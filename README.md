# SocialLang

A language for defining social games (roles, phases, actions, win conditions) that AI agents
then play. See [DESIGN.md](DESIGN.md) for the schema and examples.

Built on [MafiaSim](https://github.com/LAKSHYAJAIN16/LLM-mafia)'s LLM provider layer.

## Setup

```
pip install -r requirements.txt -r requirements-dev.txt
cp .env.example .env   # fill in your API keys
```
